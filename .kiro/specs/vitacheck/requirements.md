# VitaCheck — requirements (starter; to be refined in Kiro)

## User stories
1. As a user, I log a BP reading (systolic / diastolic / pulse) so I can track it over time.
2. As a user, I log a blood sugar reading (fasting / random) so I can track it over time.
3. As a user, I get an instant plain-language explanation of each reading, on-device, even offline.
4. As a user, I see a weekly trend report and a simple plan (meals, activity) from the cloud AI.
5. As a user, I am warned clearly when a reading needs a clinic visit.

## Acceptance criteria (starter)
- R1: Logging a reading stores it in Firestore under the anonymous user id.
- R2: Each reading gets an on-device classification + one-line summary with an "On-device" badge.
- R3: Weekly report is generated by Gemini Flash and labelled "Cloud".
- R4: Every AI answer shows the educational-info disclaimer.
- R5: Red-flag readings show a clinic-visit prompt, never a diagnosis or prescription.
- R6: The app works offline for logging + on-device classification; cloud features degrade gracefully.
